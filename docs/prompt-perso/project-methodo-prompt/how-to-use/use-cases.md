# PROJECT-METHODO-PROMPT -- USE CASES

Prompt réutilisable de la méthodo de travail personnel avec Claude Code.

- Remplir les […] et coller le prompt au démarrage d'un nouveau projet.

- Deux façons de réutiliser ce prompt

  1. Le plus simple — tu le colles en premier message de chaque nouveau projet.

  2. Le plus puissant (zéro copier-coller) — mettre le prompt dans un CLAUDE.md global (~/.claude/CLAUDE.md) : claude code le lis alors automatiquement dans tous mes projets. Idéal pour les points 1-8 qui sont universels ; je gardes juste la description du projet (point 0) en message d'ouverture.
